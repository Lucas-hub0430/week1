# Our coding style
- **Use meaningful variable names:** Always name variables based on what they hold, not just single letters.
- **Use consistent indentation:** Always use 4 spaces for indentation in Python and 2 spaces in JavaScript to make code readable.
- **Add comments for complex logic:** If a line of code is hard to understand at a glance, write a short comment above it.
- **Keep lines short:** Try to keep each line of code under 80 characters so it fits on small screens.
- **Use blank lines to separate ideas:** Put a blank line between variable declarations and the actual printing logic.
- **Always use quotes for strings:** Be consistent with either single quotes or double quotes for strings, but don't mix them.
- **End files with a newline:** Always leave one empty line at the very bottom of your code files.
